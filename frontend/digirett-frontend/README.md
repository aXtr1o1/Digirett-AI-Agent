# Digirett AI Agent Frontend

This is the React-based frontend for the Digirett AI Agent system.

## 🚀 Overview
The Digirett frontend provides a premium AI chat interface with Human-in-the-Loop (HITL) escalation capabilities, Role-Based Access Control (RBAC), and full integration with Clerk and Supabase.

## 📖 Documentation
For detailed technical information, including architecture, authentication flows, and component breakdowns, please refer to:
👉 **[FRONTEND_DEVELOPMENT.md](./FRONTEND_DEVELOPMENT.md)**

## 🛠 Quick Start
1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Configure Environment**:
   Copy `.env.example` to `.env` and fill in your keys.
3. **Start the app**:
   ```bash
   npm start
   ```

## 🏗 Key Features
- **AI Chat**: Context-aware RAG-based chat with source citations.
- **Lawyer Dashboard**: Dedicated interface for legal experts.
- **Admin Panel**: User and system management.
- **Secure Auth**: Managed by Clerk with multi-role support.
